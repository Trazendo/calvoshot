# CalvoShot

Uma extensão que permite compartilhar e visualizar imagens e GIFs diretamente nos chats da Kick, Twitch e YouTube. A extensão integra hospedagem de imagens via Catbox e busca de GIFs através do GIPHY.

## 📥 Como baixar e instalar

Como a extensão está sendo instalada manualmente fora da loja de extensões, siga os passos abaixo:

1. **[Clique aqui para baixar a extensão](https://github.com/Trazendo/calvoshot/releases/download/1.0/CalvoShot-v1.3.4.zip)**
2. Extraia o arquivo `.zip` baixado em uma pasta no seu computador.
3. Abra o seu navegador e acesse a página de gerenciamento de extensões (digite `chrome://extensions/` na barra de endereços).
4. No canto superior direito, ative o **Modo do desenvolvedor**.
5. Clique no botão **Carregar sem compactação** (ou *Load unpacked*) no canto superior esquerdo.
6. Selecione a pasta onde você extraiu os arquivos. A extensão estará instalada e pronta para uso!
